# Smart Classroom AI Lighting System — Claude Code Project

## Project Overview

This is a multi-agent AI system that optimizes electricity consumption in a classroom by intelligently controlling lights. It uses a **digital twin** (a 3D virtual replica of a real classroom) to measure and compare energy usage before and after implementing the AI system.

Built for a STEAM school fair. Everything is simulated — no physical hardware needed.

## The 5 Agents

| Agent | File | Responsibility |
|---|---|---|
| OrchestratorAgent | `agents/orchestrator/` | Receives data from all agents, makes final lighting decisions |
| VisionAgent | `agents/vision/` | Simulates camera: counts people, detects their locations |
| LightSensorAgent | `agents/light_sensor/` | Simulates natural light levels by time of day and weather |
| VoiceAgent | `agents/voice/` | Processes voice commands from the user |
| DigitalTwinAgent | `agents/digital_twin/` | Maintains the 3D classroom model, tracks energy data |

## Tech Stack

- **Backend:** Python 3.11 + FastAPI + WebSockets
- **Frontend:** React + Three.js (3D classroom) + Recharts (energy graphs)
- **AI Logic:** Rule-based + simple ML decisions (no external AI API required)
- **Communication:** REST API + WebSocket for real-time updates
- **Data:** JSON files for state, CSV for energy logs

## How to Start This Project with Claude Code

Run these commands in order. Claude Code will read each AGENT.md and build the corresponding module:

```bash
# 1. Start with the shared foundation
claude "Read shared_skills/ and set up the base project structure with FastAPI and React"

# 2. Build the digital twin first (everything depends on the classroom model)
claude "Read agents/digital_twin/AGENT.md and build the digital twin module"

# 3. Build the sensor agents
claude "Read agents/vision/AGENT.md and build the vision simulation module"
claude "Read agents/light_sensor/AGENT.md and build the light sensor module"

# 4. Build the voice agent
claude "Read agents/voice/AGENT.md and build the voice command module"

# 5. Build the orchestrator last (it connects everything)
claude "Read agents/orchestrator/AGENT.md and wire all agents together"

# 6. Build the frontend
claude "Read agents/digital_twin/skills/SKILL_3d_model.md and build the React + Three.js frontend"
```

## Classroom Configuration

The classroom is divided into **4 lighting zones**:

```
┌─────────────────────────────────┐
│  Zone A (Front-Left)  │  Zone B (Front-Right)  │
│  2 light fixtures     │  2 light fixtures      │
├───────────────────────┼────────────────────────┤
│  Zone C (Back-Left)   │  Zone D (Back-Right)   │
│  2 light fixtures     │  2 light fixtures      │
└─────────────────────────────────┘
         [Windows on left wall]
         [Door at back-right]
         [Whiteboard at front]
```

Each fixture = 40W fluorescent bulb. Full classroom ON = 320W.

## Energy Measurement Goal

The system compares two scenarios:
- **Baseline:** All 8 lights ON for 8 hours = 2.56 kWh/day
- **AI-optimized:** Lights adjusted by occupancy + natural light = target 40-60% savings

## Key Rules the AI Follows

1. If 0 people in classroom → all lights OFF
2. If natural light > 70% in a zone → lights OFF in that zone
3. If people only in zones A+B → only zones A+B lights ON
4. Voice command always overrides AI decisions
5. Log every decision with timestamp and reason
